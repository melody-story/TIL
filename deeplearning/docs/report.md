[문제 1] OpenCV와 MediaPipe를 활용한 얼굴 탐지 실습 (기본 + 가산점) 

인터넷에서 임의의 인물 이미지를 구하여 구글 드라이브나 코랩에 업로드한 후, OpenCV를 이용하여 얼굴을 탐지하는 코드를 작성하세요. 

조건: 얼굴을 감싸는 바운딩 박스(Bounding Box)의 색상을 반드시 빨간색으로 설정하여 결과 이미지를 화면에 출력하세요. (힌트: 예제 코드의 색상값인 (255, 0, 0) 부분을 수정해야 합니다) 

가산점 과제(선택): MediaPipe 라이브러리를 이용하여 눈, 코, 입, 귀 등의 주요 얼굴 포인트(Landmark)를 탐지해 보세요. 강의 시간에 다룬 기본 코드를 넘어선 본인만의 창의적인 실습(예: 특정 포인트에 가상 스티커 씌우기, 얼굴 메쉬(Mesh) 그리기 등)이 포함되면 가산점이 부여됩니다. 



[문제 2] GPT-2를 활용한 영문 문장 자동 생성 ("아무말 대잔치") 

사전 학습된 GPT-2 언어 모델을 로드하여 영문 문장을 자동으로 생성하는 코드를 작성하고 실행하세요. 

조건: 문장 생성 시, 시작점이 되는 씨드 단어(Seed words)를 최소 3개 이상 문맥에 맞게 입력해야 합니다. (예: "Data science is", "I want to" 등 어떤 문장이든 상관없습니다.)  입력한 씨드 단어 뒤로 모델이 자연스럽게 이어지는 문장을 생성하도록 하고 그 결과를 출력하세요.



[문제 3] Tesseract를 활용한 문서 이미지 글자 인식(OCR) 실습 (기본 + 가산점) 

인터넷에서 영문 또는 한글(혹은 혼용) 텍스트가 포함된 임의의 문서 이미지를 구하여 코랩에 업로드한 후, 오픈 소스 OCR 엔진인 Tesseract(pytesseract 라이브러리)를 이용하여 이미지 내의 텍스트를 추출하고 결과를 화면에 출력하세요. 

조건: 구글 코랩 환경에 맞게 Tesseract 설치 및 필요 라이브러리 임포트 코드가 반드시 포함되어야 합니다. 한글 텍스트가 포함된 이미지를 사용할 경우, 한국어 학습 데이터(kor.traineddata)를 다운로드 및 환경 변수에 적용하여 lang='kor' 또는 lang='kor+eng' 옵션으로 설정해야 합니다.
