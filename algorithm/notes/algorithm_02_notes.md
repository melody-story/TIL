## 1. 자료구조 배열 (Array)

### 1) 배열의 필요성과 특징
* **정의:** 데이터를 나열하고, 각 데이터를 **인덱스(Index)**에 대응하도록 구성한 데이터 구조.
    * 파이썬에서는 기본적으로 리스트(List) 타입이 배열 기능을 제공.
* **필요성:** 같은 종류의 데이터를 일괄적이고 순차적으로 효율성 있게 관리하기 위해 사용. 변수 이름의 남발을 막고 관련성을 부여함.
* **장점:** 인덱스 번호를 통해 빠른 데이터 접근이 가능. (첫 데이터 위치에서 상대적 위치로 즉시 찾아감)
* **단점:** 중간에 데이터를 추가하거나 삭제하기 어려우며, 선언 시 **미리 최대 길이를 지정**해야 함.

### 2) Java의 자료형 특성
* **Primitive 자료형 vs Wrapper 클래스**
    * `int`와 같은 기본(Primitive) 자료형과 `Integer` 같은 클래스 객체 형태가 존재.
    * **Wrapper 클래스 사용 이유:** `Null`을 용이하게 처리할 수 있고, `ArrayList`처럼 객체만을 취급하는 Java 컬렉션 기능들을 활용하기 위함.

### 3) 배열의 선언과 구조
* **배열 선언 방식:**
    ```java
    int[] a; // 주로 권장되는 방식 (타입[] 변수명)
    int a[]; // 다른 방식
    a = new int[5]; // 길이가 5인(0~4 인덱스) 배열 요소 생성
    
    // 선언과 동시에 배열 초기화
    int[] b = {1, 2, 3, 4, 5};
    ```
* **구조적 이해:** 
    * `a`는 배열 변수(참조 변수)이며, 실제 데이터가 담기는 본체를 참조(가리킴)함.
    * 배열 생성 시 각 구성 요소는 자동으로 `0` (int의 경우)으로 초기화됨.
    * `a.length`를 통해 배열의 구성 길이를 알 수 있음.

## 2. 배열을 활용한 주요 알고리즘

### 1) 배열의 최댓값(Max) 구하기
```java
max = a[0]; // 기준값을 첫 요소로 설정
for(int i = 0; i < n; i++) {
    if(a[i] > max) {
        max = a[i]; // 순차 탐색하며 기존 최대값보다 크면 갱신
    }
}
```
* **동작 방식:** $O(n)$ 시간에 요소들을 한 번씩 순회하면서 최대값을 판별함.

### 2) 배열 값 역순 정렬하기 (Reverse)
배열의 정렬 순서를 완전히 뒤집는 알고리즘. 총 `n/2`번의 교환(Swap) 과정이 필요함.

* **인덱스 관계:** `i`번째 요소와 `n-i-1`번째 요소를 교환.
* **값 교환(Swap)의 핵심 원리:** 직접 맞바꿀 수 없으므로 임시 변수 `t`를 사용.
    ```java
    // 배열값 a[idx1]과 a[idx2]의 값을 교환하는 메서드
    static void swap(int[] a, int idx1, int idx2) {
        int t = a[idx1];      // 1. 첫 값을 t에 임시 보관
        a[idx1] = a[idx2];    // 2. 원위치에 두 번째 값을 대입
        a[idx2] = t;          // 3. 두 번째 위치에 보관해둔 t값 대입
    }
    ```

### 3) 다차원 배열
* 배열을 구성값(요소)으로 갖는 배열.
* **2차원 배열:** 행(Row)과 열(Column)로 구성 (가장 빈번하게 쓰임).
    * `int[][] x = new int[2][4];` (2행 4열)
* **3차원 배열:** 2차원 배열을 구성값으로 가짐. 
    * `int[][][] y = new int[2][3][4];`
