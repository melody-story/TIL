## 1. 자료구조와 알고리즘 개요

### 1) 자료구조 (Data Structure)
* **정의:** 데이터를 담는 구조. 코드 상에서 효율적으로 데이터를 처리하기 위해 데이터 특성에 따라 체계적으로 구조화한 것.
* **목적:** 대량의 데이터를 효율적으로 관리. 접근 및 수정을 가능하게 하는 조직, 관리, 저장 방법.
* **일상 속 예시:**
    * **매표소 줄:** 큐 (Queue)
    * **계획 리스트:** 리스트 (List)
    * **책을 쌓아두는 것:** 스택 (Stack)
    * **사전/조직도:** 탐색 구조 / 트리 (Tree)
    * **지도:** 그래프 (Graph)

### 2) 알고리즘 (Algorithm)
* **정의:** 어떤 문제를 해결하기 위한 방법의 절차. 저장된 데이터를 찾거나 변형, 수정할 때 필요한 방법론.
* **알고리즘의 3가지 기본 구조:**
    1. **순차 구조 (Sequence):** 처음부터 순서대로 차례차례 처리
    2. **선택 구조 (Selection):** 조건식으로 판단하여 실행할 처리를 전환 (예: If-Else)
    3. **반복 구조 (Iteration):** 조건을 만족하는 동안 같은 처리를 반복 (예: For, While 루프)
* **기술 방법 (표현 방식):**
    * **순서도 (Flowchart):** 도형 기호(터미널, 처리, 판단, 루프, 흐름선 등)를 이용.
    * **의사코드 (Pseudo Code):** 프로그래밍 언어에 의존하지 않고 사람의 언어로 절차를 기술.
    * **프로그래밍 언어:** Java, C, C++, Python 등으로 실제 코드 구현.

### 3) 프로그램 요소
* **Program = Data Structure + Algorithm**
* 명령어(Instruction)와 데이터(Data)의 집합.
* **작성 4단계:** 설계 (알고리즘 구상) ➜ 프로그래밍 (코딩) ➜ 디버깅 (오류 수정) ➜ 문서 작성 (사용자/개발자용 문서)

## 2. 알고리즘 성능 분석과 빅오 표기법 (Big-O Notation)

성능 측정은 실제 처리 시간을 재기도 하지만(하드웨어 종속됨), 주로 **연산의 횟수(n의 함수)를 분석**하여 효율성을 판단합니다.
* **시간 복잡도 (Time Complexity):** 연산 횟수에 따른 처리 시간 분석
* **공간 복잡도 (Space Complexity):** 처리에 필요한 메모리 공간 분석

### 1) 빅오(Big-O) 표기법 핵심
입력 크기 $n$에 대해 계산 횟수가 어느 정도인지를 점근적(Asymptotic)으로 대략 표현하는 방법입니다.  
가장 큰 영향을 미치는 최고차항만을 고려하고 상수는 무시합니다. (예: $5n^2 + 10n + 100 \rightarrow O(n^2)$)

> 💡 **수행 시간 비교 (빠름 ➔ 느림)**  
> $O(1)$ < $O(\log n)$ < $O(n)$ < $O(n \log n)$ < $O(n^2)$ < $O(n^3)$ < $O(2^n)$ < $O(n!)$

### 2) 대표적인 시간 복잡도 예시
* **$O(1)$ 상수형:** 해시 테이블 (입력 크기와 상관 없이 항상 일정)
* **$O(\log n)$ 로그형:** 이진 탐색 (데이터가 커져도 수행시간이 조금씩 늘어남)
* **$O(n)$ 선형:** 순차 탐색 (데이터 수와 정비례)
* **$O(n \log n)$ 로그선형:** 퀵 정렬, 병합 정렬 등
* **$O(n^2)$ 2차형:** 선택 정렬, 버블 정렬 (이중 루프)
* **$O(n^3)$ 3차형:** 삼중 루프가 있는 경우

### 3) 케이스(Case) 분석
* **Best Case (최선의 경우):** 가장 빨리 찾는 경우 (예: 순차 탐색에서 맨 앞방에 있을 때 ➜ $O(1)$)
* **Average Case (평균의 경우):** 계산하기가 까다로워 잘 쓰이지 않음 (순차 탐색 ➜ $O(n)$)
* **Worst Case (최악의 경우):** 제일 운이 나쁠 때 (예: 순차 탐색에서 맨 뒤에 있거나 없을 때 ➜ $O(n)$). **실무에서 가장 널리 기준이 됨.**
