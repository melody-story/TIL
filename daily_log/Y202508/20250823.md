# 📒 자바가 확장한 객체지향

---

## ✅ abstract 키워드 – 추상 메서드와 추상 클래스

* **추상 메서드**: 선언만 있고 구현(몸체)이 없는 메서드

  ```java
  abstract void run();
  ```
* **추상 클래스**: 추상 메서드를 포함할 수 있는 클래스 → 객체 생성 불가
* 자식 클래스에서 반드시 구현(override)해야 함 → **다형성 보장**

---

## ✅ 생성자

* 객체 생성 시 자동 호출되는 특별한 메서드
* 클래스명과 동일, 반환 타입 없음
* 오버로딩 가능 → 다양한 방법으로 객체 초기화
* 명시하지 않으면 **기본 생성자**(default constructor) 자동 추가됨

---

## ✅ 클래스 생성 시 실행 블록, static 블록

* **static 블록**: 클래스가 JVM에 로드될 때 단 한 번 실행됨 → 주로 static 변수 초기화
* **인스턴스 블록**: 객체 생성 시마다 실행 → 생성자보다 먼저 실행됨
* **생성자**: 인스턴스 블록 실행 후 호출됨

---

## ✅ final 키워드

* **final 클래스**: 상속 불가
* **final 변수**: 값 변경 불가 (상수)
* **final 메서드**: 오버라이드 불가
* 즉, `final`은 **변경·확장 금지**

---

## ✅ instanceof 연산자

* 객체가 특정 클래스의 인스턴스인지 확인

```java
if (obj instanceof String) {
    System.out.println("문자열 객체");
}
```

---

## ✅ package 키워드

* 클래스들을 **논리적 그룹**으로 묶기 위한 키워드
* 패키지 선언 예:

```java
package com.example.myapp;
```

* `import` 문으로 다른 패키지 클래스 사용 가능

---

## ✅ interface 와 implements 키워드

* **interface**: 추상 메서드와 상수(public static final)만 가질 수 있음
* **implements**: 클래스가 인터페이스를 구현할 때 사용
* 다중 구현 가능 → 자바의 다중 상속 한계 극복

---

## ✅ this 키워드

* 현재 객체 자신을 참조하는 키워드
* 용도:

  * 멤버 변수와 매개변수 구분할 때
  * 다른 생성자 호출할 때 (`this(...)`)

---

## ✅ super 키워드

* 부모 클래스 멤버에 접근할 때 사용
* 부모 생성자 호출 (`super(...)`)
* 오버라이드된 메서드에서 부모 메서드 실행 가능

# 📒 자바 Optional & null 처리

---

## ✅ Optional<T> (Java 8 이상)

* `null` 방지를 위한 컨테이너 클래스
* 값이 있으면 안전 사용, 없으면 대체 처리

```java
Optional<String> opt = Optional.ofNullable("Hello");
opt.ifPresent(System.out::println);
```

* 주요 메서드:

  * `isPresent()`, `ifPresent()`
  * `orElse()`, `orElseGet()`, `orElseThrow()`
  * `map()`, `filter()`

---

## ✅ null & 빈 문자열 체크 방법

* Java 6:

  ```java
  if (str != null && !str.isEmpty()) { ... }
  ```

  공백 포함 제거:

  ```java
  if (str != null && str.trim().length() > 0) { ... }
  ```

* Java 8:

  ```java
  Optional.ofNullable(str)
          .filter(s -> !s.isEmpty())
          .ifPresent(System.out::println);
  ```

* Java 11+:

  ```java
  if (str != null && !str.isBlank()) { ... }
  ```

* Apache Commons Lang:

  * `StringUtils.isNotEmpty(str)`
  * `StringUtils.isNotBlank(str)`

---

✅ **정리:**

* 추상화(`abstract`), 상속(`super`), 다형성(`interface`), 객체 자신(`this`), 클래스 관리(`package`) 등은 객체지향 확장의 기초
* `final`, `instanceof`, static/인스턴스 블록은 실행 흐름 제어와 안정성 보장
* Java 8 이후는 `람다`, `Optional`, `Stream` 으로 **null 안전성과 함수형 스타일**을 도입
